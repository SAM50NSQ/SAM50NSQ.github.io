What I do

I'm an AI engineer who ships Generative AI in production, not just in notebooks. I integrate and fine-tune generative models, design the inference pipelines that serve them, and build the backend that runs those AI workloads reliably at scale.

Concretely, that means fine-tuning diffusion models with PyTorch and Hugging Face, integrating LLM and generative APIs, and engineering multi-model, multi-provider inference pipelines tuned for GPU utilisation and latency. On top of that I build agentic systems: LLM control flow with self-critique, bounded reflection, and a human in the loop where the stakes justify one. I treat evaluation as a first-class job: I built a benchmarking framework across 8 generative models so the model that shipped was a measured choice, not a guess.

My foundation runs deep on the systems side. Before the cloud work, my IEEE-published research put a neural network on bare silicon (FPGA), which is where I learned to obsess over inference speed and efficiency. That range, from how a model runs on hardware up to how it serves real users, shapes how I build AI that is both capable and fast.

Personal project
2026, open source
Agentic AI

Reflective Planning Agent

An LLM agent that criticises its own plan before it acts. Every proposed plan passes two independent critics, deterministic Python rules and an LLM judge, and then routes to one of three outcomes: revise, ask the user, or stop. The rules simulate the plan and validate the world it would produce, not the current one; the judge assesses what code cannot, such as whether the timing genuinely serves the goal. Destructive actions suspend the graph for human approval through LangGraph interrupts, while a harmless addition proceeds without asking.

intake -> plan -> critique -+-> clarify -> plan
                           +-> revise  -> plan
                           +-> confirm -> END
clarify: ask the user, capped  /  revise: regenerate, capped  /  confirm: human approves destructive changes

I hand-wired the reason, act, observe loop rather than using a prebuilt agent constructor, so that every edge out of the reflection node carries its own termination argument: revision caps, clarification caps, and stall detection on repeated findings. The write-up documents what actually broke, including a confident false positive from the deterministic checker, a critic whose findings were being discarded before the replan, and an action schema too narrow to express the correct answer, which the planner filled by confabulating one.
